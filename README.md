## Хэрэгжүүлэх алгоритм

`search.c` дотор дараах гурван функцийг гүйцээнэ.

| Функц | Үүрэг |
|---|---|
| `rk_hash(data, length)` | `BASE = 256`, `MOD = 1000000007` ашиглаж polynomial hash бодно. |
| `rk_roll(current, outgoing, incoming, high_power)` | Эхний байтыг хасаж, шинэ байтыг нэмэн цонхны hash-ийг O(1) хугацаанд шинэчилнэ. |
| `search_all(text, n, pattern, m, emit, context)` | Бүх цонхоор гулсуулж, жинхэнэ тааралтын байрлалуудыг мэдээлнэ. |

`high_power = BASE^(m-1) mod MOD`. Hash-ийн утгыг үргэлж `[0, MOD)` завсарт хадгал. `uint64_t` ашиглаж үржвэрийн хязгаар болон модуль хасалтыг зөв тооц. Хоосон цувааны `rk_hash()` нь `0` байна.

**Hash тэнцүү бол текстийг байт бүрээр баталгаажуулсны дараа** `emit()` дуудна. `memcmp()`-ийг зөвхөн энэ баталгаажуулалтад хэрэглэж болно. Өөр цуваанууд ижил hash-тай байж болох тул тестэд зориуд үүсгэсэн collision орсон.

Hash тооцох ба цонх шилжүүлэх үндсэн ажил **O(n+m)**. Hash таарсан цонхны тоог `h` гэвэл баталгаажуулалт **O(hm)**, нийт хамгийн муу тохиолдол **O(nm)**. Тогтмол модультай энэ хувилбарыг бүх оролтод шугаман гэж үзэхгүй. Алгоритмын нэмэлт санах ой **O(1)**; гаралт хэвлэх зардлыг тусад нь тооцно.

## Хайлтын интерфэйс

```c
int search_all(const unsigned char *text, size_t n,
               const unsigned char *pattern, size_t m,
               match_fn emit, void *context);
```

- Тааралт бүрийн **эхлэх байтын индексийг** `emit(position, context)`-ээр яг нэг удаа, өсөх дарааллаар мэдээл. Давхцсан тааралтууд орно. `banana` дотор `ana` нь `1`, `3` байрлалд байна.
- Хайлтын дотор `printf()` дуудахгүй. Хэвлэх ажлыг бэлэн callback гүйцэтгэнэ.
- `n`, `m` урт бэлэн ирдэг. Текст дотор `0` байт байсан ч хайлт үргэлжилнэ; `strlen(text)` хэрэглэж болохгүй.
- `m == 0`, `pattern == NULL`, `emit == NULL`, эсвэл `n > 0` үед `text == NULL` бол `SEARCH_BAD_ARGUMENT` буцаана.
- Хоосон текст болон текстээс урт хэв нь амжилттай хайлт: тааралт мэдээлэхгүй, `SEARCH_OK` буцаана.
- Санах ой хүрэхгүй бол `SEARCH_NO_MEMORY`. Callback тэгээс өөр утга буцаавал шууд зогсоож `SEARCH_OUTPUT_ERROR` буцаана.
- Нэг процесс дотор өөр текст, өөр хэвээр дахин дуудахад зөв ажиллах ёстой. Өмнөх оролтын уртыг `static` хувьсагчид хадгалж үлдээж болохгүй.

`strstr()`, regex эсвэл өөр алгоритмаар үндсэн хайлтыг орлуулахгүй. Тест зөв хариуг шалгана; шаардсан алгоритмыг хэрэглэснийг багш кодоос давхар шалгана.

## Команд ба гаралт

```text
./mygrep [-i] [--] PATTERN FILE
```

`-i` нь **зөвхөн ASCII `A–Z` үсгийг** `a–z` болгоно. `search_all()`-д аль хэдийн хувиргасан байтууд ирнэ. Гаралтад файлын анхны байт хэвээрээ гарна. UTF-8 текстийг яг байтаар нь хайж болно; кирилл үсгийн том/жижиг хувиргалт энэ даалгаварт орохгүй. `-`-аар эхэлсэн хэвийг `--`-ийн дараа өг: `./mygrep -- -i example.txt`.

Тааралт бүрт дараах **бичлэг** гарна:

```text
мөрийн_дугаар: context
```

Мөрийн дугаар **0-ээс эхэлнэ**, тааралт **эхэлсэн** мөрийг заана. `context` нь тааралтын өмнөх хамгийн ихдээ **5 байт**, хэв бүхэлдээ, дараах хамгийн ихдээ **5 байт**. Context дотор шинэ мөр байвал хэвээр хэвлэгдэх тул нэг бичлэг дэлгэцэнд хэд хэдэн мөр болж болно. Файлын төгсгөлийн дараах хиймэл `NUL` хэвлэхгүй.

```bash
printf 'banana' > example.txt
./mygrep ana example.txt
```

Зөв гаралт:

```text
0: banana
0: banana
```

Олдохгүй бол юу ч хэвлэхгүй, exit code `0`. Хоосон хэв, буруу аргумент, файл унших алдаа нь stderr тайлбартай, exit code `2`. `./mygrep --help` тусламж харуулна.
